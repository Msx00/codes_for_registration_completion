# Liver2 — AI-oriented project structure
# Generated 2026-08-05

# SEMANTIC OVERVIEW:
# This is a 3D liver point-cloud completion & deformation research codebase.
# It has TWO independent research tracks:
#   TRACK A: "compeltion-only" — liver shape completion via SplAttN (Split-Attention Network)
#   TRACK B: "PIVOTS" — liver surface deformation prediction (P_V2S_Net)
# Plus a deprecated "completion-old" that hybridizes SplAttN + Physics3D simulation,
# and a "completion" variant using SPAQNet instead of SplAttN.

# ============================================================
# TOPOLOGY: import dependency chain (bottom-up)
# ============================================================
# utils/ → models/ + metrics/ → core/ → config_*.py → main_*.py
# Entry scripts (train_completion.py) wrap main_*.py with argparse
